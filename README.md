# Linear Algebra Project (PR3)

## 📌 Project Overview

This project demonstrates the practical implementation of Linear Algebra concepts using Python. A student marks dataset is used to understand vector operations, matrix operations, linear transformations, and eigenvalue decomposition.

The project is developed using NumPy and Pandas in Jupyter Notebook.

## 🎯 Objectives

- Understand the basic concepts of vectors and matrices.
- Perform different vector operations.
- Calculate vector norms, dot product, and cross product.
- Perform matrix addition, multiplication, transpose, and inverse.
- Understand linear transformations in 2D and 3D.
- Calculate covariance matrix, eigenvalues, and eigenvectors.

## 📊 Dataset Description

The dataset contains marks of 5 students in three subjects.
